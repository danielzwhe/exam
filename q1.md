# Question

A student must solve an entire workbook of problems related to finding the area of intersection of two circles. Because the problems are all very similar, the student decides to write a program that can solve all these similar problems.

## Input

The first line of the input consists of an integer centerX1, representing the x coordinates of the center of the first circle
The second line consists of an integer centerY1, representing the y coordinates of the center of the first circle.
The third line consists of an integer radius1, representing the radius of the first circle.
The fourth line consists of an integer centerX2, representing the x coordinates of the center of the second circle.
The fifth line consists of an integer centerY2, representing the y coordinates of the center of the second circle.
The last line consists of an integer radius2, representing the radius of the second circle.

## Output

Print a real number representing the area of intersection of two circles rounded up to 6 decimal places.

## Constraints

0 < radius1, radius2 < 10^4

## Example

**Input:**

```
0
0
2
3
0
2
```

**Output:**

```
1.813247
```

## Explanation

First circle has center coordinates as (0,0) and radius 2.
Second circle has center coordinates as (3, 0) and radius 2.
The area of intersection of two circles is 1.813247.
